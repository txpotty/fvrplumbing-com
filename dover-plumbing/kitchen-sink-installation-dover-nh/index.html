    Stainless Sinks With Sound Pads in Dover

    Cheap stainless bowls are noisy when dishes hit them or the disposal runs. Better sinks come with rubber pads and an undercoating, and if yours does not, we can add a coat of spray undercoating before it goes in. It is a small thing.     Double Bowl Sink and Continuous Waste in Dover

    A double bowl drains both sides through one trap, using either a center outlet continuous waste or an end outlet tee. The layout depends on your disposal and dishwasher, because the disposal side changes where the tee sits and how much slope each bowl gets. We use heavy-wall fittings.

    Farmhouse Sink Installation in Dover, NH

    A fireclay apron sink sits on a frame inside the cabinet, not on the countertop. We build that frame from 2x4s or a steel bracket, set the sink dead level and leave the right reveal for the stone shop. Drain placement is planned early. A lot of them drain toward the back, so the trap layout has to match.

    Restaurant Sink Installation in Dover

    Workstation Sink Installation in Dover, NH

    Drop-In Kitchen Sink Installation in Dover
