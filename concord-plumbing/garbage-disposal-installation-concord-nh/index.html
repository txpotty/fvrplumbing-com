    Every Kind of Disposal Install, Done Properly in Concord, NH

    Disposal Rough-In for New Construction in Concord

    At rough-in we set the drain height and the outlet location before the cabinets go in. For a kitchen with a disposal, we usually set the drain stub lower than a plain sink would need, so the trap can sit below the disposal outlet with room for proper fall. The electrician adds the switched outlet. Its location gets marked to stay clear of the trap.

    First-Time Disposal Installation in Concord

    For kitchens that have never had a disposal, we start by checking the sink flange, drain height and electrical supply. The mount goes on, the unit gets hung and the discharge tube is connected to a new trap, with the wall stub lowered if it sits too high. Power comes from a licensed electrician when needed.

    Commercial Disposal Installation in Concord

    Commercial disposals run 1 to 5 horsepower and usually need a dedicated circuit, a control panel and a water solenoid. We set the unit on the mounting collar, run the drain to the grease trap where the local rules require it, and wire the controls so the water runs whenever the motor does. Health codes vary. We check the requirement before we order anything.

    Batch-Feed Units for Kitchens Without a Switch in Concord

    Batch-feed disposals only run when the stopper lid is in place, which adds safety for families with kids. They need no wall switch, so they are a good choice for kitchens where adding a switch would mean cutting into finished drywall or tile backsplash. Mounting and drains are standard.

    Disposals in Remodels and New Builds in Concord

    On new builds and remodels in Concord, we work with your contractor so the disposal, the sink and the dishwasher are planned together. That usually means a dedicated circuit for the disposal, a drain stub set low enough for the trap and a dishwasher hose path that allows a proper high loop or air gap. Planning early saves rework.

    Disposal Upgrades in Concord, NH

    Upgrading from an old 1/3 HP unit to something quieter is a common request. We disconnect and remove the old disposal, check the trap and drain arm for corrosion, and install the new unit with a new mount, so the upgrade does not inherit the old unit's worn parts. Old drain arms often need replacing. Rust works from inside galvanized pipe.

    Air Switch Disposal Installation in Concord, NH

    Air switches start the disposal with a button on the sink or counter. The button pushes air through a tube to a control box in the cabinet, which keeps electricity away from the button and avoids a new wall switch. Islands use them often.

    High-Horsepower Disposal Installation in Concord

    A 3/4 or 1 HP unit is bigger and heavier than a starter model, so we measure the cabinet first. Taller units can push the discharge outlet below the wall stub, and when that happens we either lower the drain at the wall or pick a model with a higher outlet so water does not sit in the chamber. Power needs a check too. A larger motor pulls more current when it starts.
