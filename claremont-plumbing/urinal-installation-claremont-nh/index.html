    Home urinals use the same rules as commercial ones.     Accessible urinals start at the carrier. We set the carrier so the finished rim lands at 17 inches or lower, keep the clear floor space free of partitions and door swings, and mount the flush handle or sensor where a seated user can reach it. We measure the rim twice. Inspectors measure too.

    Urinal Upgrades and Water Savings in Claremont, NH

    Older urinals often use 1.5 gallons or more per flush.     ADA-Compliant Urinal Installation in Claremont

    At least one urinal in a public restroom with more than one usually has to be accessible. The flush handle has to be easy to reach. We mark it all during rough-in.
