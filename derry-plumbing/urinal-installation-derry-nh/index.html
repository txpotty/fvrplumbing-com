    Flushometer Urinal Installation in Derry

    Manual flushometers are still the most common setup. Manual valves go on a 3/4 inch line with the control stop tuned and the vacuum breaker at the correct height. Handles can go left or right. ADA units need the handle within reach.

    Sloan Flush Valve Installation in Derry, NH

    Sloan Royal valves are on most commercial urinals we see. Each Sloan Royal gets the right inside parts for the bowl, a tuned control stop and a rebuild kit on hand. Sensor versions mount the same way. Battery models need no wiring.

    Flush Valve Urinal Installation in Derry, NH

    Flush valve urinals are the commercial standard. Tankless flushometers deliver a set volume from a 3/4 inch line and recover instantly for the next user. We set the volume to the bowl. Wrong settings stain bowls.

    Sensor Urinal Installation in Derry, NH

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Batteries last a few years. Hardwired units need an electrician first.

    Office and Restaurant Urinal Installation in Derry

    Restaurant restrooms see a lot of traffic in short bursts. A single urinal at a busy bar can flush a few hundred times on a Friday night, so we install fixtures and valves that recover quickly and stand up to rough handling without loosening on the wall. Vandal-resistant valves are available. Night installs keep you open.

    Residential Urinal Plumbing in Derry, NH

    Home urinals use the same rules as commercial ones. The drain is usually 2 inch, the trap is built into the china, the fixture needs a vent within code distance, and the flush valve needs either a 3/4 inch supply or a lower-flow residential valve on 1/2 inch. Your city may want a permit. We check that first.

    Urinal Replacement and Upgrades in Derry

    Cracked or stained urinals are worth replacing. Cracked china leaks eventually and heavy scale rarely comes clean, so a new bowl on the old carrier is usually best. Carrier bolts get inspected first. Rusted bolts get replaced.

    ADA Urinal Installation in Derry

    Accessible urinals start at the carrier. We set the carrier so the finished rim lands at 17 inches or lower, keep the clear floor space free of partitions and door swings, and mount the flush handle or sensor where a seated user can reach it. We measure the rim twice. Inspectors measure too.
